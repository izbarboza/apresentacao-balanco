# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repo is

A single self-contained slide presentation (`apresentacao.html`) for "Projeto Balanço" — a Rio de
Janeiro carnival percussion project (Escola de Formação, Bloco de Carnaval, Banda Show). There is no
build system, package manager, or test suite; this is not a software project in the usual sense. The
other files are source material the deck is built from:

- `apresentacao.html` — the entire presentation: HTML structure, CSS, and JS all in one file.
- `fotos/` — instrument/photo assets referenced by `<img>` tags in the deck (`fotos/<nome>.png`).
- `ecossistema.png`, `ecossistema_balanco.pdf`, `ecossistema_balanco_e_formacao_de_ritmistas_no_rio.pdf`,
  `balanco_-_..._anotações_do_gemini.docx` — background/reference material (research notes, diagrams)
  that informed the deck's content, not build inputs.

There is no git repository initialized here (despite the folder name).

## Working with `apresentacao.html`

No compiling, bundling, or dev server is needed — it's plain HTML/CSS/JS meant to be opened directly
in a browser (double-click or "Open with Chrome/Edge"). To preview: open the file in a browser; use
arrow keys / space / on-screen arrows to navigate slides, `F` for fullscreen. Printing (`Ctrl+P`) uses
the `@media print` rules to lay out one page per slide.

The file itself carries a detailed Portuguese editing guide in an HTML comment at the top — read that
before making changes. Key points from it:

- **Slide content**: each slide is one `<section class="slide">...</section>` in the "SLIDES" area,
  preceded by an identifying HTML comment (`<!-- SLIDE N: ... -->`). Edit text directly inside
  `<h1>`/`<h2>`/`<p>`/`<li>` tags for that section.
- **Colors**: centralized as CSS custom properties in `:root` at the top of `<style>` — change hex
  values there rather than hardcoding colors elsewhere. `--accent` (#056735, brand green) is the
  primary accent; `--red`/`--blue`/`--yellow`/`--purple` are secondary accents used for card stripes,
  unit cards, and pills.
- **Adding a slide**: copy an entire `<section class="slide">...</section>` block, paste it in the
  desired position (order matters — slides render in document order), edit the content. Navigation
  arrows, the dot indicator, and the slide counter are all generated by the JS at the bottom
  (`slides = Array.from(document.querySelectorAll('.slide'))`) — nothing there needs to change when
  slides are added or removed.
- **Removing a slide**: delete its `<section class="slide">...</section>` block.

Each slide tends to introduce its own small set of scoped CSS classes near the matching content (e.g.
`.eco-triangle`/`.tri-node` for slide 3's ecosystem diagram, `.compare` for slide 4, `.timeline` for
slide 8, `.barchart` for slide 11) — when editing a slide's visual layout, look for its dedicated CSS
block (labeled with a `/* ---- ... (slide N) ---- */` comment) rather than the shared `.card`/`.grid`
primitives, unless the change is meant to apply generically across slides.

Note: some scoped CSS blocks are ahead of the markup that uses them — e.g. `.eco-triangle`/`.tri-node`
exists in the stylesheet but slide 3's markup still uses the older `.cycle`/`.card`/`.arrow` layout.
Check that a slide's HTML actually references the classes you're editing before assuming a CSS change
will show up.
